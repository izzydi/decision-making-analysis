# Decision-Making Project

An academic decision-making project preserved as a written report.

## Repository contents

- [`ADM_Project.docx`](ADM_Project.docx) — complete project report.

## Project format

The substantive analysis, methodology, results and discussion are contained in the Word document. This repository is maintained as a portfolio/archive copy of the completed work rather than as an executable software package.

## How to review

Download `ADM_Project.docx` and open it in Microsoft Word, LibreOffice Writer or another compatible document viewer.

## Notes

No executable source code or dataset is currently included in the repository, so the report itself is the authoritative project artifact.
