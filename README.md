## Repository contents

- [`decision_making_report.docx`](decision_making_report.docx) — complete project report containing the methodology, analysis, results and discussion.

## Project format

This repository is intentionally report-based rather than code-based. The substantive work is contained in the Word document, so the repository is maintained as a portfolio/archive copy of the completed analysis instead of presenting it as an executable software package.

## How to review

Download `decision_making_report.docx` and open it in Microsoft Word, LibreOffice Writer or another compatible document viewer.

## Reproducibility note

No executable source code or dataset is included. The report is therefore the authoritative project artifact and the repository should be evaluated as a decision-analysis/reporting project rather than a reproducible software project.
